# Proje Ozeti

## Urun Amaci

Pano POS, tek urun mantiginda gelistirilecek satis altyapisidir.

Ilk cekirdekte hedeflenen alanlar:
- hizli satis
- restoran
- cari
- tahsilat
- kasa takibi
- ileride ERP entegrasyonu icin uygun altyapi

## Temel Hedefler

Sistem:
- basit olmali
- performansli olmali
- gelistirilebilir olmali
- offline calisabilmeli
- cok cihazli kullanimi desteklemeli
- moduler buyuyebilmeli
- ileride lisanslama eklenebilir olmali

## Uygulama Siniri

Bu proje ilk etapta buyuk ERP degildir.

Oncelik:
- calisan backend cekirdegi
- test edilebilir is kurallari
- satilabilir ilk urun

## Ilk Asama Disi Konular

Simdilik cekirdekte yazilmayacak:
- lisans servisi
- ERP entegrasyon servisi
- e-fatura servisi
- yazarkasa/POS entegrasyonu
- terazi entegrasyonu
- recete ve uretim detaylari
- gelismis stok fisleri
- merkez sync ve conflict yonetimi
- memory cache
- React web panel
- Flutter mobil
